Design
System

One two-color palette, one monospace family, and a fixed set of rules, marks, and states. Everything in the lab is assembled from what is on this sheet.

Source screen Case Console The Case Console is the design-system source. Every other screen inherits from it.

01 / Color

#FFFFFF canvas
#C8102E ink
ink at .58 secondary
ink at .16 rule

Two colors only. No black, no gray tokens, no second accent, no gradients, no glow, no shadow. Opacity is the only secondary hierarchy.

02 / Typography

Display Case title Section heading Body copy. A calm security researcher documenting evidence for another expert. Small label / 12px / semibold / sentence case

Berkeley Mono, SF Mono, IBM Plex Mono, Geist Mono, then system monospace. Never Courier. Sentence case throughout; no letterspaced all-caps.

03 / Spacing and rules

4 / 8 / 12 / 20 / 32 / 48 / 72 / 104 / 144

solid rule / structural division

rule / component division

hairline / row division

dashed / shadow-only and provisional states

Corner radii: 8px controls, 12px surfaces, full pill for chips and buttons.

04 / Status patterns

blocked shadow-only enforced control case

Status is carried by label, fill, and rule style. Solid fill means a decided outcome; a dashed outline means shadow-only.

05 / Controls

tag label REDACTED R

Focus is a 2px red outline at 3px offset, always visible. Touch targets are at least 44px.

07 / Motion

  • Selection and disclosure: 160ms. Stage transitions: 220ms.
  • Replay beats: 300ms apart, reduced to zero under reduced-motion.
  • Permitted: opacity, fill, and width transitions on a single easing curve.
  • Forbidden: bounce, float, glow, spring, parallax, blink.
Content rule: all copy states what happened and what did not happen. No threat-eliminated language, no invented scan results, no claim that a fixture proves a production defense.
